# 用部分充电时间估电池 SOH:五种经典机器学习的对比与复现

配套文章:`用部分充电时间估电池 SOH:五种经典机器学习的对比与复现`

## 这是什么

在同一份数据、同一套划分、同一套指标下,让**五种经典机器学习 + 四类特征组**同台竞技,
看"部分充电时间(PCT)"这个特征到底能撑起多少精度。

## 目录

```
code/
  bench_extract.py    从原始循环数据提取特征 → features.csv
  bench_run.py        五种模型 × 四组特征 × 两种划分,产出 benchmark_results.json
  plot_bench.py       误差对比图
  plot_soh_curve.py   SOH 曲线与预测对照图
data/
  features.csv        提取好的特征表(可直接跳到 bench_run.py)
  benchmark_results.json  跑分结果
figures/              文章用图
article/              原文章节(Markdown)
```

## 运行

```bash
pip install scikit-learn pandas numpy matplotlib
cd code
python bench_run.py       # 约 1~3 分钟(CPU)
python plot_bench.py
python plot_soh_curve.py
```

`bench_extract.py` 需要原始 NASA 循环数据;仓库已附 `features.csv`,一般无需重跑提取。

## 模型清单(实测:6 个模型 + 1 个基准)

| 编号 | 方法 | 随机划分 RMSE | 跨电池 RMSE |
|---|---|---|---|
| M1 | PCT + SVR | 3.079% | 3.980% |
| M2 | **PCT + 随机森林** | **1.224%** | **1.788%** |
| M3 | 弛豫 14 点 + 随机森林 | 1.627% | 2.822% |
| M4 | 弛豫 14 点 + 高斯过程 | 1.765% | 4.975% |
| M5 | 端电压统计 + 线性回归 | 1.463% | 2.553% |
| M6 | 全特征 + 梯度提升 | 0.826% | 1.710% |
| M7 | **猜均值(基准)** | 5.078% | 6.067% |

> ⚠️ **注意**:文章标题写的是"五种经典机器学习",而本仓库脚本实际包含 **6 个模型 + 1 个猜均值基准**
> (M6 全特征+梯度提升是后续补充的)。引用时请以此表为准。

**两个值得注意的点:**

1. **同一个特征,换模型差 2.5 倍** —— PCT+随机森林(M2)比 PCT+SVR(M1)在随机划分下好 2.5 倍;
2. **跨电池划分一律变差** —— M4 高斯过程从 1.765% 掉到 4.975%(R² 0.037,几乎等于瞎猜),说明它对电池个体极敏感;
   **M2 相对最稳**(1.224% → 1.788%),R² 仍保持 0.876。

## 两种划分

- **random**:随机划分训练/测试(论文里常见,偏乐观)
- **lobo**:Leave-One-Battery-Out(留一电池,**更接近实际部署**)

**两者的差距就是"过拟合到特定电池"的代价。**

## 指标

`RMSE_pct` / `MAE_pct` / `MAPE_pct`(百分比口径)、`R2`。

## 说明

- 数据来源:NASA PCoE 电池老化数据集(B0005/B0006/B0007/B0018 等)。
- 代码为复现所用,不做过度封装,便于逐段核对。
- 若把本方法与其他论文的数字并列,请注意**划分方式必须一致**(random vs lobo 差距很大)。
